Full-stack + Unity 2D

Я программист полного цикла: работаю и с интерфейсами, и с серверной частью. Создаю сайты на HTML, CSS, JavaScript и PHP, проектирую базы данных в MySQL. Для сложных проектов использую Vue на фронтенде и Laravel на бэкенде. Отдельное направление — интерактивные лендинги: параллакс-эффекты, анимации при скролле и другие динамичные сценарии.

Помимо веб-разработки, в качестве хобби создаю 2D-игры на Unity с использованием C# — под мобильные телефоны и компьютеры. Уверенно работаю с физикой, анимацией и игровыми интерфейсами.
